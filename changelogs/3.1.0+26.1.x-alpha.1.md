# Frostful 3.1.0 Alpha 1: Multiloaderification

Multiloaderifies Frostiful using Neo Loom and Forgified Fabric API for Neoforge support. This means I do not have to maintain two separate branches for Fabric and Neoforge which was a huge pain for me.

**IMPORTANT:** This version probably does not work as well as the current stable 3.0 version, so it is released initially as an alpha. Please report any issues to Github: https://github.com/TheDeathlyCow/frostiful/issues
