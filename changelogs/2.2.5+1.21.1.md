# Frostiful 2.2.5+1.21.1

* Added a new client config option: `disableHurtPolarBearSkin`.
* This option allows users to disable the hurt texture of a brushed polar bear (client side) to improve compatibility with resource packs.
* This option is set to `false` by default.
* Updated Ukrainian translations, thanks [Usia](https://crowdin.com/profile/usia)!
