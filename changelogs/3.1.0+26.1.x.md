# Frostiful 3.1.0 for Minecraft 26.1.x

This is a full release for the Multiloader version of Frostiful for 26.1.x.

Changelog:
- Converted Frostiful to a multiloader project for Fabric and Neoforge support
  - The Neoforge version of this mod requires FFAPI. I have no plans to remove this dependency at this time.
- Added limited support for the Programmer Art resource pack, which includes the following textures that were previously included with a release of Frostiful, but was later removed:
  - Fur armor item and entity models
  - Fur padded chainmail armor item and entity models
  - Frost wand item model
  - Freezing wind gust particle
- Renamed the Warmth mob effect to Warmhearted
  - This change was aliased so `frostiful:warmth` will refer to `frostiful:warmhearted`, no worlds should break from this change.
  - Warmhearted now also provides complete immunity to cold-environment temperature changes.
  - This effect has new icon
- Added a new Warming mob effect
  - This effect warms the target by 5% of their max coldness per second, per level.
  - This effect only applies to cold entities, and so is strictly beneficial.
- Sun Lichen now apply the Warming effect instead of applying instant heating. 
- The campfire now provides 5 seconds of Warming I and 60 seconds of Warmhearted I
- Added a new Freezing mob effect
  - This works similarly to Warming, but freezes its target instead.
  - This effect only applies to cold entities, and so is strictly harmful.
  - I plan to remove this effect and alias it to the vanilla effect in 26.4+.
- Potion of Freezing was renamed to Potion of Numbing to reduce confusion.
- Potion of Numbing was given the effects Freezing and Slowness in addition to Frost bite.
  - This change has been aliased for all the old freezing potion types.
- Added a new icon for the Freezing effect (it is a custom icon, not the vanilla icon from 26.4 pre releases).
- Added a snowflake particle.
  - This particle is used for the effect particles of the Freezing effect
- Made all soups (except for suspicious stew) and stews warm, including the vanilla items.
- Added a new item data component `frostiful:post_consume_effects` to handle and configure the behaviour of warm foods tag
- Warm foods now provide 30s of Warmhearted I and 5s of Warming I
- Added a new hot foods tag for spicy foods that applies 60s of Warmhearted I and 5s of Warming II
- Added a cold foods tag to disable this behaviour for some items (it is empty by default)
- Tags are now all placed under the `food_temperature` sub-folder. For example, `frostiful:food_temperature/warm`, `frostiful:food_temperature/hot`, `frostiful:food_temperature/cold`
    - The `frostiful:warming_foods` tag will still work, but it should be considered deprecated
- Replaced the freezing wind particle animation with a new and improved animation.
    - The old animation is now included in the programmer art resource pack
- Removed the `frostiful:wind_flipped` particle type.
- The `frostiful:wind` particle parameters have been updated.
    - Added a `y_angle` field which controls the angle the particle renders at.
    - Removed the `flipped` field.
- Moved glacial arrow and freezing wind entities to the misc mob category.

Config schema version 3:
- Renamed `campfireWarmthTimeMultiplier` to `campfireWarmheartedTimeMultiplier` in the block settings (applied automatically with schema v2)
- Added `campfireWarmingTimeMultiplier` that is similar to `campfireWarmheartedTimeMultiplier` but specifically for the Warming effect
- Added `enableCampfireLogs` option to the block settings that allows users to enable/disable this feature entirely
